# History Coffee — веб-админка

Панель для владельца и сотрудников кофейни: новости (с push-уведомлением),
меню, обращения гостей, контакты и часы работы, сотрудники, базовая аналитика.

React 19 + Vite + TanStack Query. Работает с тем же API, что и приложение (`/api/v1/admin/*`).

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173, /api проксируется на http://localhost:3000
API_PROXY=http://localhost:3100 npm run dev   # если backend на другом порту
```

Первый администратор создаётся backend-ом из `ADMIN_BOOTSTRAP_EMAIL` /
`ADMIN_BOOTSTRAP_PASSWORD`, остальных сотрудников он добавляет в разделе «Сотрудники».

## Роли

| | Редактор | Администратор |
|---|:-:|:-:|
| Новости, меню, обращения, обзор | ✓ | ✓ |
| Контакты и часы работы | | ✓ |
| Сотрудники | | ✓ |

## Сборка

```bash
npm run build        # статика в dist/
```

По умолчанию API ищется по относительному пути `/api/v1` (админка и API за одним
доменом через reverse-proxy). Другой адрес задаётся при сборке: `VITE_API_URL=https://api.example.ru/api/v1`.
